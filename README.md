
# Customer Churn Prediction with PySpark

Predicting customer churn using Apache Spark and machine learning.

## Overview

This project explores customer churn through exploratory data analysis, preprocessing, feature engineering, and classification using PySpark MLlib.

## Objectives

- Explore customer behavior and churn patterns
- Prepare numerical and categorical features
- Train a Decision Tree classifier
- Evaluate predictive performance
- Investigate the impact of tree depth

## Tech Stack

Python · PySpark · Spark MLlib · pandas · NumPy · Matplotlib · Plotly

## Machine Learning Workflow

1. Data loading and exploratory analysis
2. Missing-value analysis and preprocessing
3. Categorical encoding and numerical scaling
4. Feature vector assembly
5. Train/test split (70/30)
6. Decision Tree classification
7. ROC-AUC evaluation and model-depth exploration
