# Model Artifacts

This directory contains the serialized machine learning pipeline used by the Customer Churn Prediction application.

## Deployed Model

**File:** `customer_churn_pipeline.joblib`

- **Framework:** scikit-learn
- **Selected algorithm:** Logistic Regression
- **Serialization:** Joblib
- **Purpose:** Customer churn probability estimation
- **Training workflow:** `notebooks/01_customer_churn_sklearn.ipynb`

The artifact contains the fitted preprocessing pipeline and classification model.

It is intentionally version-controlled so the Streamlit application can load the trained pipeline without retraining it during deployment.

## Model Performance

Results from the held-out test set:

| Metric | Value |
|---|---:|
| ROC-AUC | 0.8418 |
| Average precision | 0.6334 |
| Accuracy | 0.74 |
| Churn precision | 0.51 |
| Churn recall | 0.78 |
| Churn F1-score | 0.61 |
| Decision threshold | 0.50 |

These metrics describe the evaluation performed in the scikit-learn notebook. They do not guarantee equivalent performance on new customer populations.

## Reproducibility

The model can be regenerated by executing the scikit-learn training notebook with compatible dependencies and the public IBM Telco Customer Churn dataset.

The deployed artifact was created using scikit-learn 1.6.1. Loading serialized scikit-learn models requires compatible library versions.

Only load Joblib artifacts from trusted sources. Deserialization may execute arbitrary code.

## Version Control

The deployed `customer_churn_pipeline.joblib` file is intentionally tracked in Git.

Other generated model artifacts are excluded by default through `.gitignore`.

## Limitations

This model is provided for educational and portfolio demonstration purposes.

- Predictions are estimates, not guarantees of customer churn.
- Probability calibration has not been independently established.
- The 50% decision threshold is a baseline rather than a business-optimized threshold.
- The model should not be used for real customer retention decisions without additional validation and monitoring.

For the complete methodology, see the repository's main README and training notebooks.
